# TP1
Este repositorio presenta mi primer acercamiento al desarrollo web. El proyecto consiste en la maquetación de mi currículum vitae, adaptando mi perfil al formato HTML5 y CSS. Fue realizado como trabajo práctico para la materia Computación III en la Universidad Nacional de Lanús (UNLa).
El proyecto fue construido a través de diferentes etapas. Esta entrega representa la versión final.

## Para la construcción de este sitio se utilizaron las siguientes herramientas y propiedades:
* HTML5
* CSS
* Flex Box
* Box Model

##Editor de código utilizado: Visual Studio Code.
El diseño y la maquetación fueron realizados en Visual Studio Code. La resolución de pantalla es de 1920 x 1080 píxeles.
